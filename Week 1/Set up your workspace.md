# How to start the course Introduction to programming

## Install Visual studio

1. Google Visual Studio
2. Download and install Visual Studio Community Edition for C++ 

## Test the compiler

1. Create a new project - **Console application for C++** or **Empty project for C++**. (Ctrl + Shift + N)

2. Add a new file to the project **main.cpp**

3. write the following code in main.cpp

   ```c++
   #include <iostream>
   using namespace std;
   int main() {
   	cout << "Hello, world!";
   }
   ```

4. Run the project (F5 or Ctrl + F5)

5. If everything is successful you should see a console with the text **Hello, world!**.
