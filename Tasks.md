# Tasks for Introduction To Programming

1. Write `Hello, world!` on the console.
2. Write the words `one, 2, three` on the console, each of them on a new line.
3. Write `John said, “No”`. on the console.
4. Create a variable with the value `12` and print it on the console.
2. Create two variables with values `3` and `7`. Print them on the console. Make a third variable holding their sum. Print the sum on the console.
3. Create 2 variables. Ask the user to input 2 numbers and save them in the variables. Print the product of the 2 numbers.
7. Create a variable holding the letter `A`. Add `1` to the variable. Print the variable.
8. Create 2 variables representing the 2 sides of a rectangle with values `3.4` and `10.0`. Print the area of the rectangle.
9. Calculate the roots of `x^2-130x-4056`.
10. Calculate the circumference of a circle with radius `0.159154943`, knowing that `Pi = 3.141592654`.
11. Calculate the face of a circle with radius `0.564189584`. Before printing the result include the library `<iomanip>` and write `cout << setprecision(10);`.
12. Create 2 variables, assign them values and swap their values. Print the swapped values.
13. Print the value of `5 == 5`.
14. Print the size of `int` (how many bytes each int has).
15. Find the maximum value of `unsigned int`.
16. Create a variable with value `325`. Print the variable as a char.
17. Create a variable holding the letter `E`. Print the variable as int.
18. Write a function which prints `Hello, world!`.
19. Write a function which has one int parameter and prints that parameter to the console.
20. Write a function which calculates the sum of 2 ints.
21. Write a function which calculates the product of 2 chars.
22. Write a function which accepts 4 coordinates in the form (x1, y1, x2, y2) and calculates the distance between the points with coordinates (x1, y1) and (x2, y2).
23. Write a function which finds how many digits a number has.
24. Write a function which prints all the digits of a number on new lines.
25. Write a function which reverses a number.
26. Write a function which takes an int and prints all its divisors.
27. Write a function which calculates the real roots of a quadratic equation of the form `a*x^2 + b*x + c = 0`. The function takes 3 parameters - `a, b, c`.
28. Write a function to calculate the `N`th Fibonacci number where `N` is the parameter of the function.
29. Write a function which takes in a char and returns its hex value if it’s a valid digit `{ 0-9, A-F }`.
30. Write a function which accepts an array of integers with 5 elements and subtracts 1 from each element.
31. Write a function which takes a string and prints it reversed.
32. Write a function which takes an enum `WeekDay` and prints the weekday as a string on the console. e.g `printDay(Monday);` outputs `Monday` on the console.
33. Write a function which takes one integer as a parameter and prints on the console all its divisors.
34. Write a function which accepts an array of integers of arbitary size and makes all the integers negative. (Hint: the function must also accept the size of the array. Array and pointer here are interchangeable)
35. Write a function which takes an array (pointer), its size and element we are looking for and retuns the index at which that element is found in the array or -1 if the array doesn’t have such element.
36. Create a string variable (char array). Find the length of the string and print it on the console.
37. Write a function which accepts an array of char with arbitary number of elements and returns the all the elements.
38. Write a function which accepts 2 arrays of integers with 3 elements and adds the elements of the second array to the first. As a result `arrayOneProcessed[i] = arrayOne[i] + arrayTwo[i]`.
39. Write a function which takes a string and determines if it is a palindrome. A palindrome is a string which is read the same way forwards and backwards.
40. Write a function which takes in a string and prints what characters we need to add to the end for it to become a palindrome.
41. Write a function which takes an array of integers and outputs all the even numbers on the console.
42. Write a function which takes an array of chars and calculates the average of all odd numbers.
43. Write a function which takes an array of integers and reverses it.
44. Create a struct representing a point with 2 integer coordinates. Write a function which finds the distance between 2 points.
45. Create a struct representing a point with 2 float coordinates. Write a function which finds the distance between 2 points. 
46. Create a struct representing a 3x3 matrix. Write a method to add two matrices.
47. Create a struct representing 5x5 matrix. Write a method to transpose the matrix.
48. Create a variable `D` with value `420`. Create another variable `X` of the same type. Create a pointer to the variable `X`. Try to find the address of `D` by moving the pointer around.
49. Determine if your machine is using little or big endianness.
50. Write a recursive function which takes one integer parameter. The function calculates the sum of all numbers between 0 and the parameter.
51. Write a recursive function to calculate the `N`th Fibonacci number.
52. Write a recursive function to compute factorial.
53. Write a recursive function which counts the digits of a number.
54. Write a recursive function which prints the binary representation of a number in reverse.
55. Write a recursive function which calculates the power of a given integer.
56. Write a recursive function which finds the max number in an array.
57. Print all possible numbers with up to 5 digits containing the numbers `1,2`.
58. Write a recursive function which prints all integers less than 1000.
59. Write a recursive function which takes an integer array and a number N. The function prints all possible combinations of N elements of the given array.
